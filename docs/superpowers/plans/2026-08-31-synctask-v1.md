# SyncTask V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Android-first SyncTask V1 Flutter app from `.raw/prd.md`, `.raw/DESIGN.md`, and the supplied `.raw/*-st.png` wireframes.

**Architecture:** Create a local-first Flutter app using SyncSpend-style `core / features / shared` boundaries, Riverpod controllers, Drift persistence, `go_router`, and Android notification services. Keep task planning, focus execution, insights, lists, search, and settings separate so Focus never completes tasks and Tasks never own timers.

**Tech Stack:** Flutter, Dart, Riverpod 3, `riverpod_annotation`, Drift, `drift_flutter`, `go_router`, `shared_preferences`, `flutter_local_notifications`, `timezone`, `flutter_timezone`, Firebase Core, Crashlytics, Analytics, Inter font.

**Spec:** `.raw/prd.md`, `.raw/DESIGN.md`, `.raw/home1-st.png`, `.raw/home2-edit-st.png`, `.raw/home3-edit-st.png`, `.raw/home-threedot-st.png`, `.raw/upcoming-st.png`, `.raw/focus1-st.png`, `.raw/focus2-st.png`, `.raw/list-st.png`

## Global Constraints

- Android V1 only.
- Local-first and fully usable offline.
- No login, cloud account, cross-device sync, Pro, paywall, subscription, or lifetime purchase.
- Notion must appear as `Coming Soon` and must not perform functional sync in V1.
- Bottom navigation must be exactly `Today | Upcoming | Focus | Lists`.
- Search is accessible from the Today header only.
- Insights is accessible from the Focus header only.
- Use Inter everywhere with `letterSpacing: 0`.
- Use semantic theme tokens; do not hardcode widget colors.
- Visual identity must be quiet, monochrome, editorial, functional, and spacious.
- Do not include purple Toki visual language, mascot visuals, preset focus durations, session counters, priority controls, tags, subtasks, flags, nested folders, or automatic task completion after Focus.
- Every task belongs to exactly one folder; Inbox is permanent.
- Focus Timer is optional on task creation/edit, but task-linked Focus requires a saved duration.
- Standalone Focus has no default duration and Start remains disabled until duration is selected.
- `focus_history` stores completed Focus runs only.
- Stopped or cancelled Focus runs never enter Insights/history.
- Activity grid intensity is based on completed Focus run count.
- Recurrence supports Daily, Weekly, Monthly only.
- Monthly recurrence rule for V1: if the anchor day does not exist in the target month, schedule on that month's last valid day while preserving the original anchor day for later months.
- Recurrence uses series plus exactly one active occurrence; no backlog generation.
- Device reboot does not restore active Focus; stale active timer state is discarded at next app launch.
- Analytics and Crashlytics must never include task titles, folder names, reminder text, search strings, or other user-entered content.
