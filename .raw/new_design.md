# Design System: New Design

## Typography

- **Primary font:** NotionInter
- **Font fallback:** Inter, -apple-system, system-ui, "Segoe UI", Helvetica, Arial
- **Letter spacing:** Varies by typography role; display and heading styles use negative tracking, while body, buttons, captions, and most small text use 0.
- **Heading style:** Heavy, tight, quiet-confident; primarily weight 700 with increasingly negative letter spacing at larger sizes.
- **Largest heading:** 64px / 700 / line-height 1.0 / letter-spacing -2.125px
- **H1:** 40px / 700 / line-height 1.1 / letter-spacing -1px
- **H2:** 26px / 700 / line-height 1.23 / letter-spacing -0.625px
- **H3:** 22px / 700 / line-height 1.27 / letter-spacing -0.25px
- **Title:** 20px / 600 / line-height 1.4 / letter-spacing -0.125px
- **Body text:** 16px / 400 / line-height 1.5 / letter-spacing 0
- **Small body:** 15px / 400 / line-height 1.33 / letter-spacing 0
- **Caption:** 14px / 400 / line-height 1.43 / letter-spacing 0
- **Small labels:** 12px / 600 / line-height 1.33 / letter-spacing +0.125px

## Shapes & Component Sizing

- **Card radius:** 12px
- **Large container radius:** 16px
- **Input radius:** 4px
- **Button shape:** Fully pill-shaped / 9999px radius for marketing CTAs; utility buttons use 8px radius.
- **Primary CTA height:** Not explicitly specified in the source design.
- **Icon button size:** Not explicitly specified in the source design.
- **Expense icon size:** Not applicable / not specified in the source design.

## Layout & Spacing

- **Spacing system:** 4px, 8px, 12px, 16px, 24px, 28px, 32px
- **Screen gutter:** Generous responsive outer gutters; no fixed pixel value specified.
- **Card padding:** 24px
- **Section spacing:** Large vertical gaps; no single fixed value specified.

## Shadows & Elevation

- **Shadows:** Barely-there layered micro-shadows using multiple near-transparent black layers.
- **Elevation style:** Hairline borders plus subtle layered shadows rather than heavy drop shadows. Most default cards are flat with a hairline border; raised surfaces use soft multi-layer shadows.
